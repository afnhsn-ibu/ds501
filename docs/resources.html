Resources

Running the code

Every lab opens in Google Colab from its week page. Nothing needs installing on your own machine, and every dataset loads from a public URL. For a local setup, install Python 3.11 or later plus the packages listed at the top of each notebook.

References you will use every week

  • pandas user guide and API reference
  • NumPy reference
  • matplotlib and Plotly galleries
  • scikit-learn user guide
  • SQLite documentation, for Week 4
  • Apache Spark Python API, for Week 11

Datasets

Palmer Penguins, Telco churn, Chinook, Titanic, Gapminder, Diamonds, COMPAS, and open data from North Macedonian portals. All public.

Getting help

Ask in class, in the course channel, or in office hours. If you are stuck on code, bring the error message and the smallest example that produces it.

Fixing this site

This site is a public repository. Found a broken link, a wrong date or a typo? Open an issue or send a pull request. Corrections are welcome and credited.
