Introduction to Data Science

Twelve weeks that follow one path: a question, the data that answers it, the understanding you build from it, the models you fit, how you communicate the result, and what you owe the people in the data.

a question→data→understanding→models→communication→responsibility

One session of about three hours each week: three 45-minute lessons and a practice.  ·  International Balkan University, Skopje  ·  2026–27 Fall

Before the first class

Open a Google account you can use with Colab, read the syllabus, and start thinking about a question you would like to answer with data. You choose a project topic in Week 1 and confirm it in Week 3.

Key point: start with the decision someone would make differently if they knew the answer, not with the dataset.
